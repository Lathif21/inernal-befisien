Befisien is a confident blue-and-white brand for an Indonesian IT and digital-transformation consultancy. The same system covers the public site **befisien.com** and the internal **Befisien CRM & Keuangan** app. The site is airy and illustrative. The app is denser and built for scanning. Both use one palette, one typeface and the same shapes.

## Content

- **Language:** all UI copy is **Bahasa Indonesia**. Code, comments and commit messages are English.
- **Voice:** plain, direct and work-focused. Use "kami" for Befisien on the website. Address the user implicitly in the app ("Langkah berikutnya untuk deal ini?").
- **Casing:** sentence case for buttons, headings and labels ("Tambah langkah", "Rencana strategi"). Uppercase only for `eyebrow` group labels ("TERLAMBAT · 2").
- **Buttons start with a verb:** "Buat Proyek", "Tambahkan ke rencana", "Jadwalkan konsultasi". Use "Nanti saja" or "Abaikan" for the soft option.
- **No emoji anywhere.** Use Lucide icons or text.
- **Money:** IDR, no decimals. Full form `Rp 12.500.000` (dot thousands) in tables and forms. Short form `Rp 12,5 jt` / `Rp 1,2 M` on cards, tiles and charts. Income always carries `+` and expense `−` next to the colour, so meaning never depends on colour alone.
- **Dates and times:** `22 Okt 2026`, `22 Okt 10:00` (24-hour), `Kamis, 22 Okt 2026` in greetings. Always WIB (Asia/Jakarta). Weeks start on Monday.
- **Relative states:** "Terlambat 2 hari", "Hari ini 14:00", "Besok", "3 hari di tahap ini".
- **No invented numbers in mockups or empty states.** Use placeholders like `[XX]` until real figures exist.

## Colour

- The page ground is `tint-2`. Content sits on `surface` cards. Set text in `ink`, secondary text in `ink-2`, captions in `ink-3` (`ink-3` only on `surface` or `tint-2`).
- `accent` is the one action colour. Use it for the primary button, the active nav pill, links, the selected period, the current page in a pager and the income series. Use one primary button per view.
- `navy` is the brand's second colour. Use it for the sidebar, footer, the dark "Laba" tile, dark secondary buttons and the expense series. Text on navy uses `on-accent`, `on-dark-muted` or `on-dark-link`.
- `sky` highlights on dark or blue ground (headline accent words on the hero, the delta chip on the dark tile). On `accent`, use it only for text 24px and larger.
- `tint` softly fills kanban columns, solution cards and progress tracks.
- **Status:** use `success` / `danger` / `warning` for text and their `*-bg` tokens for soft backgrounds. Use the `*-fill` tokens only for solid marks (icons, badges, borders) with `on-accent` text. Late = danger, due today = warning, done or income = success, expense = danger.
- **AI:** everything generated by AI, and nothing else, uses `ai`, `ai-bg`, `ai-chip-bg` and `ai-line`. This keeps AI suggestions visibly separate from data the team entered.
- **Pipeline stages** deepen from `stage-lead` to `stage-negotiation` as a deal gets closer to closing. Won is `success-fill` and lost is `danger-fill`.
- **Charts:** `chart-income` (blue) beside `chart-expense` (navy) differ in lightness, not just hue. Draw planned amounts in `chart-planned` with a hatch.
- **Never use:** gradients other than the logo mark's own, purple outside AI content, or pure grey neutrals (every neutral leans blue).

## Type

- One family: **Plus Jakarta Sans** (Google Fonts, weights 400–800) through `--font-sans`. Use **JetBrains Mono** 500 (`--font-mono`) for times, invoice numbers, counters and rank numbers only.
- **App scale:** `page-title` (one per page), `greeting`, `kpi`, `section-title`, `plan-goal`, `card-title`, `body`, `small`, `eyebrow`, `mono`.
- **Website scale:** `display-hero` and `display-section` on top of the app scale.
- Set `font-variant-numeric: tabular-nums` on every number that lines up: tiles, tables, amounts, times.
- Headings use weight 800 with slight negative tracking. Do not use weights below 500 for UI text.

## Space, shape, depth

- Spacing steps: `space-1` to `space-8`. Use 28px (`space-7`) page padding on desktop and 16–24px on phones. Separate sibling blocks with flex or grid `gap`, not margins.
- **Radii by role:** `radius-control` for buttons and inputs, `radius-kanban` for kanban and AI cards, `radius-card` for app cards and tiles, `radius-panel` for the greeting bar and modals, `radius-pill` for chips and nav pills, `radius-hero` only for the website hero.
- **Depth is flat by default.** White cards on `tint-2` need no shadow or border. Use `shadow-raised` for hover lift, popovers and the website finder bar, and `shadow-modal` for modals and drawers. Use `line` borders only where two white surfaces touch (inputs, tables, kanban cards).
- **Minimum tap target:** `size-touch` (44px). `size-control-sm` (36px) only for segmented buttons and small actions inside cards.

## Layout

- **App shell:** navy sidebar (`size-sidebar`) with the logo and "CRM & KEUANGAN" under it. The content column holds a white page header (title, filters, page actions, avatar) above the `tint-2` main area, max-width 1240px.
- **No global search or "+ Tambah" bar.** The Dashboard is summary-only. Records are added on their own pages (Klien, the boards, Strategi).
- **Period filter** (Harian · Mingguan · Bulanan · Tahunan · Custom + prev/next + label) looks and behaves the same on every page that has one.
- **Kanban:** columns are `size-kanban-column` wide on `tint`. Deal ✓ and Batal are collapsed to 92px. On phones the board scrolls horizontally and drag is replaced by a "Pindah ke…" menu.
- **Strategi pagination:** max **3 plan cards per page** and max **4 steps per plan card**. A card opens on the page that holds its first unfinished step.
- **Phones:** the sidebar stacks, rows wrap, wide tables scroll inside their own box, and nothing scrolls the page sideways.

## Iconography and imagery

- **Icons:** Lucide (`@lucide/svelte`), stroke 1.75 (2–2.4 for tiny arrows and checks), 18px in navigation and 15–16px inline. Icon-only buttons need an `aria-label`.
- **Logo:** the B mark with three signal arcs, gradient `#4FA3F5 → #3442D0`, with the wordmark "BEFISIEN" (800) over "TECHNOLOGIES" (700, tracked) set in Plus Jakarta Sans. In the app the second line reads "CRM & KEUANGAN" in `sky`. The mark in Assets is a vector redraw of the supplied raster logo; confirm it against the official file before print use.
- **Illustrations:** soft 3D clay renders in the brand blues on a transparent ground (see Assets → Illustrations). Use them for the website hero, solution and industry cards, login, empty states and the Saran AI header. Never as decoration inside data tables. Never use stock photos of people.

## States and feedback

- **Next action box:** late → `danger-bg` / `danger` with "Terlambat x hari"; today → `warning-bg` / `warning` with the time; upcoming → `tint-2` / `ink-2`; missing → dashed `line-strong` border with "+ Tambah langkah berikutnya".
- **Step icons:** done (filled `success-fill` check), late (filled `danger-fill` "!"), today (`warning-fill` ring), upcoming (`line-strong` ring).
- **Focus:** a solid 3px `accent` outline with a 2px offset on every interactive element.
- **Disabled:** `ink-disabled`, no hover, `cursor: not-allowed`.
- **Empty states:** one illustration, one sentence, one button.

## Accessibility

- Text pairs above meet 4.5:1, and meaningful marks (rings, borders, icons) meet 3:1, on the grounds named in each token's usage note.
- Use real `<button>`, `<a href>` and `<input>` with `<label>`. Drag and drop always has a keyboard and touch alternative.
- Charts get an `aria-label` that lists the values.

## Building with it (SvelteKit + Tailwind v4)

- Map every colour token to a Tailwind theme variable with the same name (`--color-accent`, `--color-ink-2`, …) and every radius to `--radius-*`. Components use theme classes, never hex literals.
- The class recipes in `components/bundle.css` (`bf-btn`, `bf-chip`, `bf-next`, `bf-kcard`, `bf-step`, `bf-pager`, `bf-ai`, `bf-seg`, `bf-stat`, `bf-table`, `bf-nav`, `bf-field`) are the reference for each Svelte component's markup and states. Read each component's guideline before building it.
